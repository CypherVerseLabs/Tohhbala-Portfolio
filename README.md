The Tohbala LLC website is the public-facing digital platform for Tohbala technology consulting services.

* Revenue CRM solutions
* Business automation systems
* AI-powered business platforms
* Digital transformation initiatives

The website connects customers with Tohbala services and provides access to the Tohbala OS client portal.

# Local Development

## Requirements

Install:

* Node.js
* npm
* Git

---

## Installation

Clone the repository:

```bash
git clone https://github.com/CypherVerseLabs/Tohhbala-Portfolio.git

cd modern-portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Application:

```text
http://localhost:3000
```

---

# Production Build

Create production build:

```bash
npm run build
```

Start production server:

```bash
npm run start
```
